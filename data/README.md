# Dados residenciais

Os dados de entrada e as séries temporais não estão incluídos nesta preparação
pública. Sua disponibilização depende da revisão das permissões, dos
consentimentos, da possibilidade de identificação das residências e dos
acordos institucionais aplicáveis.

O arquivo privado `Checkpoint_R5_R7_3sementes_1000MBB_com_tabelas.zip` contém
dados processados e previsões necessários às verificações locais. Ele não é
distribuído neste repositório. O endereço público de um conjunto de dados, seu
DOI ou as razões de indisponibilidade devem ser documentados antes da submissão.

Os arquivos originais `R5_padronizada.xlsx`, `R6_padronizada.xlsx` e
`R7_padronizada.xlsx`, necessários para uma execução integral desde a leitura
original, não estão no checkpoint utilizado aqui.
